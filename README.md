# 📱 Native Android Multi-Screen App

A native Android application built using Kotlin and XML in Android Studio. The app demonstrates core Android architecture components, user input handling, and multi-activity navigation with data passing.

## ✨ Features
- **User Input Handling:** Dynamic user data capture using EditText components.
- **Multi-Activity Navigation:** Seamless transition between screens using Explicit Intents.
- **Data Bundles:** Safe data passing between activities.
- **Custom Branding:** Configured custom app icons and centralized resource strings.

## 🛠️ Tech Stack
- **Language:** Kotlin
- **IDE:** Android Studio
- **UI Framework:** Android XML Layouts
- **Architecture:** Multi-Activity with Intents

## 📥 Installation
1. Go to the [Releases](../../releases) section.
2. Download `app-debug.apk`.
3. Install and run on any Android device (OS 8.0+).
